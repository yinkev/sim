# Phase 12 Implementation - `.app` Packaging

## Decision

The first Center `.app` is a repo-local macOS launcher bundle generated by `bun run package:center-app`.

It starts the existing low-resource Center development service and opens:

```text
http://localhost:6888/workspace/local-test/center
```

This intentionally avoids Electron, Tauri, native storage, signing, notarization, or a bundled database. Packaging does not change the Center local spine, profile isolation, no-telemetry default, or import-boundary architecture.

## Implemented files

```text
scripts/package-center-app.ts
package.json
.gitignore
```

Generated local artifact:

```text
.ai-bridge/artifacts/center-app/Center.app
```

The generated artifact is ignored because it is machine-local and contains the absolute repo path.

## Launch contract

```text
Center.app
  -> Contents/MacOS/Center
  -> CENTER_DEV=1 NEXT_TELEMETRY_DISABLED=1 bun run dev:center
  -> /workspace/local-test/center
```

Environment overrides:

```text
CENTER_PORT
CENTER_WORKSPACE_ID
CENTER_APP_OPEN
CENTER_APP_WAIT_SECONDS
CENTER_APP_OUTPUT_DIR
```

## Privacy

Profile data remains browser-local through `sim.center.local-spine.v1`. The app wrapper does not introduce telemetry, background sync, a new storage backend, or external network producers.
